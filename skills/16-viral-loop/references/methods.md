# Methods this skill covers

Short definitions of the master-index methods this skill owns, and how it applies each one.

## K-factor / viral loop

K = invites per user × invite conversion; cycle time is how long one loop takes. Applied only from real counts; K below 1 still lowers acquisition cost by 1 / (1 − K).

## Network effects

When a product gets more valuable to each user as more people use it. Applied only when true; most products have word of mouth, not network effects.

## STEPPS (Berger)

Social currency, Triggers, Emotion, Public, Practical value, Stories: Berger's reasons people share. Applied to judge and design what customers would share.
