# Viral loop guide

## K-factor

K = i × c, where i = invites or shares per user in a period and c = share of those that become users. Cycle time = days from a user joining to their invitees joining. Total users from one = 1 / (1 − K) when K < 1.

## STEPPS

| Reason | Question |
| --- | --- |
| Social currency | Does sharing make the sharer look good? |
| Triggers | What reminds people of it? |
| Emotion | Does it move people? |
| Public | Can others see people using it? |
| Practical value | Does it help the recipient? |
| Stories | Is it carried in a story? |

## Loop types

Gift (giver buys, recipient experiences, may subscribe), invite with a two-sided benefit, a shareable result, public use (packaging others see).

## Measure

Track share, invite sent, opened, converted, with sender ID. Without data, publish the formula and events, not an estimate.
