# Methods this skill covers

Short definitions of the master-index methods this skill owns, and how it applies each one.

## Growth model / forecast

A chain from controllable inputs to the outcome, projected over time. Applied with sourced inputs, modelled losses, scenarios and a goal check, labelled projected.

## Abraham's three ways to grow

More customers, a higher value per purchase, and more purchases per customer. Applied to show which lever moves the outcome most.
