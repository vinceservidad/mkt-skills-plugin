# Growth model guide

## Chain

Active(t+1) = Active(t) + New − Lost. New = traffic × step conversion. Lost = Active × loss rate. Revenue = active × bags per month × price.

## Settling level

If new and loss rate stay the same, active settles near New ÷ loss rate. A goal above it needs more inflow or lower loss.

## Three ways to grow

| Lever | Model input |
| --- | --- |
| More customers | New per month |
| Higher value | Price, bags per order |
| More purchases | Retention (loss rate), frequency |

## Scenarios

Base = current rates. Low and high vary labelled assumptions within what the data supports.

## Precision

Round to what the data supports; label everything forecast as projected.
