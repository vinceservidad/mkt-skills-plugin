# Churn guide

## Types

| Type | Sign | First fix |
| --- | --- | --- |
| Involuntary | Failed payment, expired card | Dunning: notice, retries, easy update, grace period |
| Voluntary | The customer cancels | Fix the reason; pause; honest save |
| Lapse | Stops ordering without cancelling | Lifecycle reminders (15-lifecycle) |
| Active risk | Pauses, complaints, usage drops | Customer success, fix the issue |

## Reasons and responses

| Reason | Response |
| --- | --- |
| Too much product, travel | Pause, skip, cadence change |
| Late delivery | Operations fix; a shipment heads-up |
| Taste or fit | A better match if one exists; otherwise let them go kindly |
| Price | Explore value; a cheaper option only if the offer has one; discount only if the owner sets it |
| Moving, life event | Pause or a kind exit |

## Never

Hide the cancel button, force a phone call or email to cancel, make the save offer block the exit, keep charging after a cancel, or message people who opted out. Regulators restrict these practices (for example FTC negative option rules in the US; check current status and date it, or mark *to confirm*).

## Verify

A save is real only if the customer is still paying after the window that matters. Compare with similar customers not offered the save.
