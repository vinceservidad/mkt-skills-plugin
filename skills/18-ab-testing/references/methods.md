# Methods this skill covers

Short definitions of the master-index methods this skill owns, and how it applies each one.

## A/B testing

Two versions shown at random to comparable traffic at the same time. Applied with a sample size from baseline and minimum detectable effect, a pre-written decision rule, and whole-week durations.

## Multivariate testing

Testing several elements and their combinations at once. Applied only when traffic supports every combination.

## Sequential / Bayesian testing

Methods that allow looking at results during a test without inflating false positives (sequential) or that report probability of being better (Bayesian). Applied only with the method's rules written in advance.
