# Methods this skill covers

Short definitions of the master-index methods this skill owns, and how it applies each one.

## Referral program

A structured way for customers to recommend the business: the moment to ask, the kit, the reward, qualification and tracking. Applied from the referral data the business already has.

## Word of mouth

Customers telling others unprompted. Applied as the baseline the program makes easier, measured by referral source and timing.
