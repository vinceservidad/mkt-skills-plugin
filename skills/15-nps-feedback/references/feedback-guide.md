# Feedback guide

## Which measure

| Measure | Question | When |
| --- | --- | --- |
| NPS | How likely to recommend, 0 to 10 | Relationship, every few months |
| CSAT | How satisfied with this | Right after an interaction |
| CES | How easy was this | After a task (support, setup, cancel) |

## Scoring

NPS = (promoters − detractors) ÷ responses × 100. Report responses ÷ sent. Responders are self-selected; a low response rate can skew either way.

## Frequency

Survey each customer no more than the interval set (for example once a quarter for NPS). Surveying everyone every month lowers response and annoys customers.

## Close the loop

Reply to detractors within days with a named person; fix what can be fixed; tell customers what changed. Ask promoters for a review or referral.

## Route

Each theme to an owner with a count; report what changed each period.
