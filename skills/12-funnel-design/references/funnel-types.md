# Funnel types

| Type | Steps | Fits |
| --- | --- | --- |
| Squeeze (lead) | opt-in page → thank-you → nurture | cold traffic, free lead magnet |
| Quiz | quiz → result → opt-in → tailored nurture | cold traffic, several segments or products |
| Tripwire (unboxing) | low-ticket offer → order bump → upsell → core | consumer offers, impulse purchases |
| VSL (presentation) | video page → order or call | warm traffic, mid-ticket |
| Webinar or challenge | registration → event → offer → replay → close | warm traffic, mid to high ticket, launches |
| Application funnel (phone) | application to qualify the buyer → qualifying call → close | high-ticket services |
| Bowtie | the left side acquires; the right side onboards, expands and refers | subscriptions and B2B |

## Stages

- **TOFU:** strangers; give free value.
- **MOFU:** engaged leads; give proof and a demonstration.
- **BOFU:** ready to buy; give the offer and the terms.

## Customer Value Optimization (DigitalMarketer)

Lead magnet → tripwire → core offer → profit maximizer → return path. Use it to check a funnel for a missing stage; a stage with no real offer is a gap.

## Funnel hacking

Reviewing a competitor's public funnel step by step. It is evidence about that competitor, with date and source, not proof that the same type works for this offer.

## AARRR (McClure)

Acquisition, Activation, Retention, Referral, Revenue. Name the metric each step moves.
