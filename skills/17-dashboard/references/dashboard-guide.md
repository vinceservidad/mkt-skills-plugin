# Dashboard guide

## North star tests

Reflects value customers get; leads to revenue; the team can move it; measurable from the system of record.

## Driver tree example (subscription)

Active subscribers = previous active + new subscribers − cancellations
New subscribers = sessions × conversion rate
Cancellations = active × churn rate (voluntary + involuntary)

## Definitions

Each metric: definition, grain, source, refresh, owner, known issues.

## Cut

Likes, followers, impressions and platform-only conversions are signals for channel reviews, not the main view.

## Rhythm

Weekly for drivers, monthly for the north star and unit economics. Each metric names the decision it informs.
