# Methods this skill covers

Short definitions of the master-index methods this skill owns, and how it applies each one.

## North Star Metric

One metric that captures value delivered to customers and predicts revenue. Applied with a clear definition and the drivers beneath it.

## KPI tree / driver tree

A tree that breaks the north star into input metrics with formulas. Applied so each team metric visibly moves the top.

## Dashboards

A view of the metrics that matter, for a review rhythm. Applied with definitions, sources, owners, fewer than a dozen main numbers, and data issues noted.
