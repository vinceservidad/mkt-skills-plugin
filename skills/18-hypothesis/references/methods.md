# Methods this skill covers

Short definitions of the master-index methods this skill owns, and how it applies each one.

## Hypothesis format

Because [evidence], we believe [change] for [audience] will move [metric] by [size]; we'll know when [measure] after [duration]. Applied to every idea, with evidence or the label opinion.

## ICE / RICE / PIE

Scoring frameworks: ICE (impact, confidence, ease), RICE (reach, impact, confidence, effort), PIE (potential, importance, ease). Applied one per backlog, each score with its reason.

## Minimum Viable Test

The smallest experiment that would teach the most about a hypothesis. Applied before building a full version.

## Build–Measure–Learn

Ries's loop: build the smallest thing, measure, learn, decide. Applied as the order of tests and what each result changes.
