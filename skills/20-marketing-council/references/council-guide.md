# Council guide

## Viewpoints

| Viewpoint | Checks |
| --- | --- |
| Customer | Is it about their problem, in their words? |
| Copy and message | Promise, proof, clarity, call to action |
| Offer and price | Terms true, margin, risk |
| Brand | Voice, assets, consistency |
| Compliance | Claims, consent, urgency, platform rules |
| Data | Can we measure it? Is the audience right? |
| Operations | Can we deliver what it promises? |

## Verdict scale

Ship · ship with fixes · rework · stop.
