# Methods this skill covers

Short definitions of the master-index methods this skill owns, and how it applies each one.

## Tracking plan / UTMs / server-side tracking

The written spec of events, fields, naming, UTM conventions and where each is collected (browser or server). Applied from business questions, reconciled with the system of record, with deduplication and consent.

## First-party data / CDP

Data the business collects directly (orders, emails, survey answers), and a customer data platform that unifies it if needed. Applied with consent, minimisation, and a CDP only when the stack requires one.
