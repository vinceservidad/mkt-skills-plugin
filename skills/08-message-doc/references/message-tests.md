# Message tests

## Rule of One (Masterson & Forde)

| One… | Ask |
| --- | --- |
| idea | Can the whole message be said in one sentence? |
| reader | Is it written for the ICP at the right awareness level, not for everyone? |
| emotion | Which single feeling does it lead with (relief, pride, safety…)? |
| action | What is the one next step? |

## SUCCESs (Heath, Made to Stick)

| Letter | Test |
| --- | --- |
| Simple | the core, without qualifiers |
| Unexpected | it breaks a belief the buyer holds (often the enemy) |
| Concrete | a picture or a number from evidence |
| Credible | proof available (see proof-stack) |
| Emotional | it touches the job's emotional side |
| Story | it can be told as a before-and-after |

## 4 Ps (Masterson) and 4 Us (Bly) for the promise

- **4 Ps:** Promise, Picture (the after-state), Proof, Push (a reason to act). The message house holds the first three; Push comes from `07-bonuses-urgency`.
- **4 Us:** Useful, Urgent, Unique, Ultra-specific. Score the promise against each. Use specificity only where the offer can keep it.

## Benefit ladder

Feature → functional benefit → emotional benefit → value to the person. Climb until the rung matches the job in `customer.md`.

## Enemy guidelines

- **Good enemies:** a false belief ("profit on paper means safe"), an outdated method ("books at tax time"), a frustration everyone shares.
- **Avoid:** naming or insulting competitors, inventing a conspiracy, or blaming the customer.
