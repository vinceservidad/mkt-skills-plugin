# Methods this skill covers

Short definitions of the master-index methods this skill owns, and how it applies each one.

## Growth loops

Cycles where each cohort's output brings the next. Applied with step rates, multiplier per cycle, cycle time, whether the loop closes, and the weakest step.

## Flywheel

Collins's image of momentum built by connected parts. Applied to show how loops feed each other and which friction slows them.
