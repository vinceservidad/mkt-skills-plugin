# Filing examples

| Field | Values |
| --- | --- |
| Type | ad (search, social, video), headline, email, landing page, sales page, VSL, post |
| Section | offer, message, headline, lead, proof, close |
| Awareness level | unaware, problem aware, solution aware, product aware, most aware |
| Structure | PAS, BAB, AIDA, story, offer lead, big secret, testimonial, listicle… |
| Angle | outcome, problem, mechanism, proof, identity, objection |
| Why it works | one line |
| Source | brand, channel, date, link |
| Performance | only if the source shows it; otherwise "unknown" |

## Where to collect

- Ad libraries (the platforms' public ad libraries).
- Competitors' landing pages and emails (subscribe).
- Your own best performers, with their data.
- Classic collections: cite the book and page, and copy text only from the actual source.

## Borrow vs copy

- **Borrow:** the structure, the angle, the sequence, the rhythm.
- **Never copy:** the wording, slogans, trademarks or claims.
