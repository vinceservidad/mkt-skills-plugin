# Methods this skill covers

Short definitions of the master-index methods this skill owns, and how it applies each one.

## Conversion rate optimization (CRO)

The discipline of raising the share of visitors who take the target action by finding and removing the reasons they don't, then testing the fix. Every finding needs evidence (analytics, recordings, user tests or surveys), and a change is proven only by a valid test.

## MECLABS sequence

MECLABS's conversion heuristic C = 4m + 3v + 2(i - f) - 2a: motivation weighs most, then the clarity of the value proposition, then incentive minus friction, minus anxiety. Use it to order findings, not as a score.

## Heuristic evaluation (Nielsen)

An expert review of an interface against Jakob Nielsen's ten usability heuristics (for example visibility of system status, error prevention, recognition over recall). It finds likely problems fast but is a hypothesis list until users or data confirm them.

## Fogg Behavior Model

B = MAP: a behaviour happens when motivation, ability and a prompt meet at the same moment. If the action is not happening, ask which one is missing; most page fixes raise ability (less effort) or improve the prompt.

## Behavioral nudges

Small design changes that make the desired choice easier or more salient (defaults, ordering, progress cues, social proof). Use only honest nudges: no fake scarcity, pre-ticked add-ons or confirmshaming.

## Personalization

Changing page content by segment, source or behaviour. Worth it only when segments truly need different messages and traffic is large enough to measure each variant; respect consent for any personal data used.

## User testing

Watching real target users attempt a task on the page and think aloud. Five users usually reveal the main usability problems; record what they do, not what they say they would do.

## Live chat

A human answering visitor questions on the page. Useful for high-consideration purchases; mine the chat logs for objections and missing information the page should answer.

## Chatbots / conversational marketing

Automated or AI chat that qualifies, answers and routes visitors. Script it from real questions, hand off to a person quickly, never invent answers about price, terms or availability, and disclose that it is a bot.
