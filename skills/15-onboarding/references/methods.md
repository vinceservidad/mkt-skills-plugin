# Methods this skill covers

Short definitions of the master-index methods this skill owns, and how it applies each one.

## Onboarding

Everything from payment to the customer's first result. Applied as the path to first value, keeping necessary steps, answering common questions before they come, and measuring by cohort.

## Activation / aha moment

The moment a new customer first gets the value they bought. Applied as a definition in customer terms with a window and a denominator, never a tracking-convenience event such as an email open.
