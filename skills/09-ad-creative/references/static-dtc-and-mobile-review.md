# Static DTC Creative Direction and Mobile-First Review

Use when concepts include static ads, carousels, visual render specifications, or mobile feed/Reels creative reviews. Defer image/video asset prompt generation itself to `09-image-video` while supplying complete creative direction here.

## 1. Static DTC direction workflow

1. **Define the emotional job:** name the felt shift in second one (e.g., skepticism to proof, overwhelm to clarity, guesswork to certainty) anchored in buyer evidence.
2. **Write one visual thesis:** state the visual contrast executing the angle (clutter vs calm, vague promise vs measurable fact) so visuals prove the copy rather than decorating it.
3. **Lock reading hierarchy (1 → 2 → 3):** (1) hook/visual tension, (2) product recognition + proof beat, (3) CTA/offer condition as `offer.md` states it. Never compress a vague prompt like *premium aesthetic* — specify actual `brand.md` codes (or mark brand styling *unverified* if absent).
4. **Master canvas and centered 1:1 cross-crop core (only when square survival is needed):**
   - For a `1080 x 1350` (`4:5`) master expected to crop to centered `1080 x 1080` (`1:1`), keep hook copy, key product identity, material proof, CTA, and critical human features inside `y=135..1215` (treating top/bottom `135` px bands as expendable scenery/bleed).
   - **Never call 1:1 a universal platform safe zone:** Stories/Reels have asymmetric UI overlays verified against channel specs (`11-paid-social` / *to confirm* in Ads Manager preview).
5. **Separate visual base from typography overlay:** specify background composition + negative space separately from exact headline copy, line breaks, relative scale, alignment, and high contrast (handoff pixel generation to `09-image-video`; image models misrender small exact claims).
6. **Preflight every derivative crop** before launch and label assets draft until human approval.

## 2. Nine-criterion mobile-first review (for image/video concepts and revisions)

Inspect only what is actually provided (mark unrendered video pacing/audio checks *not inspected* when reading scripts only):

| Criterion | Operational check |
| --- | --- |
| Brand ID | Brand/product recognizable early without heavy logo bumper delays |
| Key brand message | Supported proposition clear from the opening frames/lines alone |
| Attention immediacy | First-second visual contrast/tension fits angle (hypothesis, not guarantee) |
| Sound-on & sound-off | Core message works muted via readable text/captions; audio adds value when unmuted |
| Mobile framing & safe zones | Legible at mobile scale; clear of both `1:1` crop bands and placement UI overlays |
| Call to action | Matches exact next action and destination in `offer.md` |
| Lift alignment | Construct aligns with intended ad/brand objective (measurement design stays with `17-incrementality`) |
| Complementary assets | Fills an evidenced format/message gap (not duplicate resizing) |
| Audience relevance | Matches buyer situation and verified language without stereotyping or unverified assumptions |

For catalog/modular sets, verify every SKU shares every static claim (never let a single-SKU certification, shipping promise, or guarantee apply misleadingly across incompatible items).
