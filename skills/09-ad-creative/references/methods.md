# Methods this skill covers

Short definitions of the master-index methods this skill owns, and how it applies each one.

## Native advertising

Paid placements styled to match the surrounding content (in-feed posts, sponsored articles, recommendation widgets). Label them as ads as the platform and law require; the creative still needs a clear hook and a promise the landing page keeps.

## Visual hierarchy

The order in which the eye reads a frame: one dominant element (the hook image or headline), then the supporting line, then the call to action. Check each concept at thumbnail size; if the dominant element is not obvious in one glance, the hierarchy is wrong.
