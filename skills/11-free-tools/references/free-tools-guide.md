# Free tools guide

## Types

| Type | Example | Good when |
| --- | --- | --- |
| Calculator | Runway, payback, cost of a problem | The buyer has a numeric question the offer answers better |
| Template | Spreadsheet, checklist | The buyer does the job themselves today |
| Grader or audit | Score a site, a set of books, a page | The result shows a gap the offer closes; must be honest |
| Generator | Names, headlines, plans | The output is useful on its own |
| Interactive guide | Quiz to a recommendation | Several products or paths |

## Fit test

1. Do buyers ask this question already (Voice of customer, tickets, calls)?
2. Can the tool give a clear, honest answer?
3. Does the answer point to the offer without a bait-and-switch?
4. Can people find it (search, partners, sales)?

## Existing resources first

If a checklist or template is downloaded but downloaders are never followed up, the cheapest win is follow-up (`12-email-sequences`), not a new tool. Count downloads, leads and clients first.

## Data

- Ask only what the result needs.
- Financial, health and personal figures are sensitive. Prefer computing in the browser without storing; if storing, state what, where, how long and who can see it, next to the form.
- Email capture is optional; the consent wording is the owner's.
- Privacy laws (for example US state laws, UK and EU GDPR) apply to what is stored; verify or mark *to confirm*. Not legal advice.

## Build decision

Cheapest test: a spreadsheet, a no-code form, or the calculator inside a call. Full build: the quote plus hosting and upkeep. Needed to justify = full cost / (value of a client × share of tool users who become clients); with no data for the share, write the formula and run the test first.
