# MKT Skills (Claude Plugin)

133 evidence-led marketing skills for Claude, Cowork, and Claude Code: a diagnosis router (`00-router`) plus 132 skills across 20 sections covering market research, customer research, positioning, offers, copywriting, creative strategy, paid ads, shopping feeds, local SEO, marketplaces, WhatsApp, funnels, CRO, sales, retention, referrals, measurement, experimentation, growth, and operations.

Includes an optional read-only MKT Skills connector (`https://mktskills.com/mcp`) for authorized report files and selected reporting accounts.

Built by [Vince Servidad](https://www.vinceservidad.com/) · Website: <https://mktskills.com> · Support: <https://mktskills.com/support>

## Install

In Claude Code 2.1.275 or later:

```
/plugin install mktskills-marketing --marketplace vinceservidad/mkt-skills-plugin
```

On older versions, add the marketplace first, then install:

```
/plugin marketplace add vinceservidad/mkt-skills-plugin
/plugin install mktskills-marketing@mkt-skills-plugin
```

## Full Skills Repository

For CLI install (`npx skills add vinceservidad/marketingskills`), Cursor, Codex, and Antigravity, see <https://github.com/vinceservidad/marketingskills>.
